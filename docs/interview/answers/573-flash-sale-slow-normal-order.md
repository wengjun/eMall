# 573 秒杀开始后普通下单也变慢，怎么止血？

[返回按分类学习面试题](../README.md)

## 题目

秒杀开始后普通下单也变慢，怎么止血？

## 先给面试官的短答案

说明秒杀流量与普通下单共享了网关、线程池、连接池、库存热点或数据库资源。应立即按活动流量隔离和限流，
优先恢复普通交易 SLO，再定位哪个共享资源达到饱和。

## 核心拆解

- 按流量标签比较普通与秒杀请求的队列等待、线程池、连接池、数据库分片和库存锁等待。
- 秒杀使用独立入口、资源池和队列，热点 SKU 单独限额；普通订单保留最低容量和独立熔断策略。
- 暂停或降低活动放量，关闭非核心推荐与报表，不能让秒杀请求无限堆积。
- 用混合流量压测验证隔离性，门禁应同时检查普通下单成功率和活动吞吐。

## 深度完善：生产事故 Runbook

围绕「秒杀开始后普通下单也变慢，怎么止血？」，事故题不要直接猜根因。高分回答要按时间线推进：先止血，再定位，再恢复，
最后补齐长期防线。面试官更看重你是否能控制影响面，而不是一次性猜中答案。

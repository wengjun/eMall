# 557 库存出现少量超卖，怎么定位和修复？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

立即停止受影响 SKU 的继续销售并保留库存快照，然后核对库存主事实、库存桶、预占流水和订单时间线。
根因通常在无条件更新、桶汇总双事实、重复消费或补偿并发，修复后需逐单确定履约或退款方案。

## 核心拆解

- 按 SKU、仓库和时间窗口计算可售、预占、已扣、已释放及实物库存不变量，确认超卖规模。
- 检查 SQL 是否使用条件扣减和期望版本，库存桶是否存在跨桶超发或异步汇总覆盖。
- 冻结热点 SKU，降低并发并暂停可疑补偿任务；不得直接把负库存改为零掩盖证据。
- 对无法履约订单执行业务补偿并通知用户，增加并发集成测试、库存对账和超卖告警。

## 深度完善：生产事故 Runbook

围绕「库存出现少量超卖，怎么定位和修复？」，事故题不要直接猜根因。高分回答要按时间线推进：先止血，再定位，再恢复，
最后补齐长期防线。面试官更看重你是否能控制影响面，而不是一次性猜中答案。

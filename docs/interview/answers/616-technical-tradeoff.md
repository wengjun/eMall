# 616 讲一次你做出技术取舍的经历。

[返回按分类学习面试题](../README.md)

## 本题考察

取舍必须存在真实代价。不要讲“既提升性能又降低成本且没有缺点”的故事，应展示你如何在一致性、可用性、速度、成本或复杂度之间做可辩护选择。

## 选材与证据

- 定义约束和优先级，说明哪项指标不能退让、哪项可以阶段性接受。
- 至少比较两个可行方案，包括不做改变这一选项。
- 说明选择的副作用、缓解措施、可逆性和演进触发条件。
- 用上线数据验证主要假设，并承认没有达到预期的部分。

## 追问准备

准备回答为什么没有选更简单或更先进的方案、代价后来是否真的发生，以及今天重新决策会改变什么。

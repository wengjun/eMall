# 558 库存预占记录大量过期未释放，怎么恢复？

[返回按分类学习面试题](../README.md)

## 题目

库存预占记录大量过期未释放，怎么恢复？

## 先给面试官的短答案

先按过期时间统计悬挂预占并控制新增规模，再检查订单终态事件、释放消费者、延迟任务和补偿游标。
释放必须以预占记录为事实，通过状态条件和幂等键执行，不能直接批量增加可售库存。

## 核心拆解

- 区分订单仍有效、已支付、已取消和不存在四类预占，只有满足业务条件的记录才能释放。
- 检查取消 Outbox、Kafka lag、消费者 DLQ、定时扫描分片覆盖和时钟偏差。
- 暂停重复失败的扫描任务，按仓库和 SKU 限速恢复，防止释放洪峰锁住库存表。
- 使用 reservationId 条件更新一次性释放，随后对账可售量、预占流水和订单状态。

## 深度完善：生产事故 Runbook

围绕「库存预占记录大量过期未释放，怎么恢复？」，事故题不要直接猜根因。高分回答要按时间线推进：先止血，再定位，再恢复，
最后补齐长期防线。面试官更看重你是否能控制影响面，而不是一次性猜中答案。

# 208 如何做灰度开关和功能开关？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

灰度开关用于按用户、商家、地区、流量比例或版本逐步放量；功能开关用于快速开启、关闭或降级某个能力。
生产级开关要支持规则配置、实时生效、审计、回滚、默认值、过期清理和监控。

开关不是 if 判断那么简单，它是发布风险控制工具。

## 常见规则

规则包括：

- 按用户 ID。
- 按商家 ID。
- 按地区。
- 按客户端版本。
- 按流量百分比。
- 按白名单和黑名单。
- 按实验分组。

规则要稳定命中，不能每次请求随机变化。

## 开关设计要点

要点包括：

- 默认值安全。
- 配置变更可审计。
- 支持快速回滚。
- 规则可测试。
- 命中结果可观测。
- 开关有负责人。
- 开关有过期时间。
- 移除过期代码。

长期不清理的开关会让代码复杂度上升。

## 风险控制

高风险功能发布流程：

```text
内部白名单
-> 小比例用户
-> 单地区
-> 扩大流量
-> 全量
```

每一步观察错误率、延迟、业务指标和用户反馈。

## 电商系统实践

新优惠计算逻辑可以先对内部员工和少量商家开启。

如果订单金额异常、错误率升高或支付转化下降，立刻关闭开关回到旧逻辑。

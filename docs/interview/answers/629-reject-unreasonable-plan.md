# 629 讲一次你拒绝不合理方案的经历。

[返回按分类学习面试题](../README.md)

## 本题考察

反对不是情绪表达。应展示你能指出具体风险、提供可交付替代方案，并在最终决定后承担共同结果。

## 选材与证据

- 先确认对方真正的业务目标和截止时间，避免反对一个误解后的方案。
- 用数据、故障场景或合规约束量化风险，区分不可接受底线与个人偏好。
- 给出缩范围、灰度、延后或可回滚的替代路径。
- 若风险超过授权范围，透明升级；决策确定后完整执行并监控。

## 追问准备

准备解释对方为何最初坚持、你的表达是否伤害合作、最终是否证明你判断正确，以及如果你错了如何承认。

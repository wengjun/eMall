# 553 设计一次数据库扩容和迁移方案。

[返回按分类学习面试题](../README.md)

## 题目

设计一次数据库扩容和迁移方案。

## 先给面试官的短答案

数据库扩容迁移应采用可恢复的在线状态机：先建目标分片并全量回填，再用 CDC 追平增量，
通过影子读和校验确认一致后分批切换路由。每一步都要幂等、限速、可暂停并有明确回滚边界。

## 核心拆解

- 迁移单元按主键范围或逻辑分片划分，持久化游标、源目标校验和、路由版本及任务状态。
- 回填避免长事务和 OFFSET，CDC 事件携带源位点；目标端按版本或更新时间拒绝旧写覆盖新写。
- 切换前做记录数、字段摘要和业务对账，先影子读再灰度读，最后在写入栅栏保护下切主路由。
- 监控复制延迟、校验差异、源库负载和失败重试；路由切换后保留回退窗口，再安全下线旧分片。

## 深度完善：系统设计高分展开

围绕「设计一次数据库扩容和迁移方案。」，系统设计题要按目标、规模、架构、数据、失败路径、演进六层展开。
不要只画组件图，必须讲清每个组件为什么存在，以及它如何在大促和故障场景下保持可控。

通用的六层分析、可恢复数据模型和取舍表达集中在
[共享模型：系统设计回答框架](../shared-answer-models.md#系统设计回答框架)。本题应继续围绕上文列出的领域不变量展开，
不能机械套用通用的电商表结构和中间件清单。

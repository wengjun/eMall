# 451 错误预算是什么？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

错误预算是 SLO 允许的不可靠额度。例如月可用性目标是 99.9%，那一个月允许约 0.1% 的请求失败或
不可用。错误预算用于平衡稳定性和迭代速度。

预算消耗过快时，应减少高风险发布，把精力转向稳定性修复。

## 基本含义

如果 SLO 是：

```text
99.9% availability
```

则错误预算是：

```text
0.1% unavailable or failed requests
```

这给团队一个可量化的稳定性边界。

## 用途

用途：

- 指导发布节奏。
- 判断是否冻结高风险变更。
- 衡量可靠性投入。
- 避免过度追求 100%。
- 让业务和技术对齐。

错误预算把稳定性讨论量化。

## 消耗过快怎么办

动作：

- 暂停高风险发布。
- 修复高频故障。
- 增加自动化回滚。
- 加强监控和限流。
- 优先处理可靠性债务。

预算不是用完就算了，而是触发管理动作。

## 在 eMall 项目中怎么讲？

eMall 下单链路月 SLO 为 99.95%。如果大促前已经消耗了大部分错误预算，团队应暂停非必要改动，
优先修复库存超时和订单错误率问题。

这样能避免在稳定性风险高时继续叠加变更风险。

# 673 团队当前最需要解决的技术债是什么？

[返回按分类学习面试题](../README.md)

## 为什么问

愿意具体讨论技术债的团队通常更清楚风险和优先级。答案还能判断你入职后是有机会系统治理，还是只能长期绕过问题。

## 重点听什么

- 能否给出具体债务、业务影响和形成原因，而不是泛泛说“历史代码较老”。
- 债务如何排序，是否有 owner、预算、偿还触发点和阶段目标。
- 新功能交付与债务治理如何共同排期。
- 过去是否真正删除过旧系统、完成迁移或降低了风险。

## 建议追问

“哪项技术债最可能成为未来一年的生产或交付瓶颈？这个岗位能获得什么授权和资源推动它？”

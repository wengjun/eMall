## Java 工具速查

| 工具 | 输入 | 主要用途 |
| --- | --- | --- |
| Checkstyle | Java 源码 | 命名、导入、缩进等可配置规则检查 |
| SpotBugs | 编译后的字节码 | 潜在空指针、相等性、资源及并发误用等静态分析 |
| PMD | 源码 | 可疑写法、复杂度与维护性规则；重复检测通常使用其 CPD 工具 |

这些工具都不是正确性证明，不能替代编译和测试。
Checkstyle 检查不等于自动格式化；formatter/Spotless 之类才负责修改格式。

Maven 中需要区分插件的报告目标与使构建失败的检查目标，并显式绑定阶段。
SpotBugs 依赖已编译的 class；若只运行早期源码检查，不能假设字节码分析也已完成。

学习时会阅读失败报告、定位规则、解释或修复问题即可，不必把三个工具的全部规则背一遍。

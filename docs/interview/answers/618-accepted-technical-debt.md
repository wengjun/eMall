# 618 讲一次你为了业务交付接受技术债的经历。

[返回按分类学习面试题](../README.md)

## 本题考察

高质量答案展示你能有意识地借债并按时偿还，而不是用“业务太急”解释失控代码。债务应当可隔离、可逆且不越过安全和正确性底线。

## 选材与证据

- 明确为什么收益大于短期成本，以及哪些替代方案已被排除。
- 限制债务范围，用适配层、功能开关或兼容接口保护核心模型。
- 登记 owner、影响、偿还日期和触发阈值，并获得利益相关方确认。
- 说明实际偿还结果；如果未偿还，要诚实解释当前风险和后续计划。

## 追问准备

准备回答债务是否产生事故、当时低估了什么，以及哪些债务无论多急都不会接受。

# 188 什么是数据所有权？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

数据所有权是指某类业务数据只能由一个服务负责定义、写入、校验和发布变更。
其他服务不能直接修改这份数据，只能通过拥有者提供的 API、事件或只读投影使用。

没有数据所有权，微服务就会退化成多个应用共享一个数据库。

## 所有权包含什么？

包含：

- 表结构定义权。
- 写入和更新权。
- 业务规则校验权。
- 状态流转控制权。
- 数据质量责任。
- 对外契约发布权。
- 数据变更事件发布权。

拥有者不仅拥有数据，也承担数据正确性的责任。

## 为什么重要？

数据所有权能避免：

- 多服务同时写同一张表。
- 业务规则散落在多个服务。
- 状态被绕过非法修改。
- 表结构变更影响未知调用方。
- 故障时无法确定责任边界。

它是服务自治的基础。

## 使用他人数据的方式

其他服务可以：

- 调用 API 查询。
- 订阅领域事件。
- 构建本地只读投影。
- 通过数据平台做离线分析。

不能直接写对方数据库表。

## 在 eMall 项目中怎么讲？

订单数据归订单服务所有，库存数据归库存服务所有，支付单数据归支付服务所有。

推荐服务可以订阅订单完成事件训练模型，但不能直接更新订单表里的状态。

# 552 设计支持 10 万下单 QPS 的交易链路。

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

十万下单 QPS 不能依赖一个同步大事务。同步链路只完成幂等校验、价格快照、库存预占和订单落库，
非关键动作通过 Outbox 异步执行；网关准入、分片数据库和库存桶共同把竞争限制在可控范围。

## 核心拆解

- 客户端幂等键加数据库唯一约束保证一次创建，订单状态更新使用期望旧状态或版本条件。
- 用户、订单和库存采用稳定分片策略；热点 SKU 独立限流、排队和拆桶，条件更新保证不超卖。
- 订单事实与 Outbox 同事务提交，支付、履约和营销消费者幂等，失败进入重试、死信、补偿和对账。
- 以单 Cell 实测吞吐推导实例和分片数量，同时验收 P99、成功率、锁等待、MQ lag 与库存差异。

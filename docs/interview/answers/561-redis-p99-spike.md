# 561 Redis 集群抖动，商品详情接口 P99 升高，怎么处理？

[返回按分类学习面试题](../README.md)

## 题目

Redis 集群抖动，商品详情接口 P99 升高，怎么处理？

## 先给面试官的短答案

先确认 Redis P99、超时率和商品详情回源 QPS 是否同步上升，再区分热 Key、大 Value、慢命令、网络抖动和集群迁移。
通过本地缓存、请求合并、热点隔离及受限回源保护数据库，Redis 恢复后渐进放量。

## 核心拆解

- 按命令、节点、Key 和对象大小查看延迟，检查慢日志、连接池等待、带宽、CPU、内存和集群事件。
- 对热点商品启用进程内短缓存和单飞重建，大 Value 拆分，禁止 KEYS 等阻塞命令。
- Redis 不稳定时限制数据库回源并降级非关键字段，不能让缓存故障直接形成数据库雪崩。
- 恢复后逐步提高 Redis 和回源并发，监控命中率、数据库 P99 及旧值窗口。

# 548 设计商品缓存系统。

[返回按分类学习面试题](../README.md)

## 题目

设计商品缓存系统。

## 先给面试官的短答案

商品缓存采用进程内缓存、Redis 和数据库的多级读路径，以数据库商品版本为权威事实。写入提交后通过 Outbox
发布失效或版本事件，读请求用版本化数据防止旧事件覆盖新值。

## 核心拆解

- Key 包含商品与租户维度，Value 带版本和过期时间；大对象拆分，避免热 Key 和网络放大。
- Cache-Aside 配合延迟双删或版本事件，消费者只有在事件版本更新时才失效或刷新缓存。
- 空值缓存防穿透，互斥重建和逻辑过期防击穿，TTL 加随机抖动防雪崩。
- 缓存不可用时对数据库实施并发保护；监控命中率、重建次数、旧值窗口、热 Key 和回源 QPS。

# 427 账号冻结对下单链路有什么影响？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

账号冻结会影响登录、下单、支付、优惠券使用、售后和履约变更。下单链路必须在关键节点校验账号
状态，不能只在登录时校验一次。

账号状态变更还要考虑缓存失效、正在进行的订单和用户提示。

## 校验点

校验点：

- 登录时。
- 创建订单前。
- 使用优惠券前。
- 发起支付前。
- 支付回调处理时。
- 申请退款和售后时。

冻结后不应允许继续发起高风险交易。

## 缓存问题

账号状态常被缓存。

冻结账号后要：

- 删除用户状态缓存。
- 提高 token version。
- 使旧 token 失效。
- 通知相关服务。
- 对关键接口回源校验。

否则冻结可能延迟生效。

## 已有订单

要区分：

- 已支付订单是否继续履约。
- 未支付订单是否关闭。
- 售后是否允许。
- 风控冻结是否需要人工审核。

不同冻结原因策略不同。

## 电商系统实践

大型电商系统用户因盗号风险被冻结后，下单接口和支付接口都应拒绝新交易，并返回明确提示。

如果用户已有已支付订单，履约是否暂停应由风控策略决定，不能简单删除订单或破坏支付状态。

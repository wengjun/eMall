# 627 讲一次你面对失败项目如何复盘。

[返回按分类学习面试题](../README.md)

## 本题考察

要选择真正没有达到目标的项目，并承担自己决策中的责任。把失败包装成“最后大获成功”会削弱可信度。

## 选材与证据

- 清楚说明原目标、实际结果和影响，不把原因全部归给资源或他人。
- 分析当时有哪些弱信号、错误假设和决策机制导致问题未被及时纠正。
- 说明如何止损、照顾用户和团队，并保存可复核事实。
- 将教训转成评审门禁、实验方式或阶段性检查点，并举出后续应用证据。

## 追问准备

准备回答你个人最大的错误、何时本应停止项目、向谁道歉或解释，以及今天会提前验证哪项假设。

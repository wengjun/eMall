# 580 生产数据库误删数据，如何恢复？

[返回按分类学习面试题](../README.md)

## 题目

生产数据库误删数据，如何恢复？

## 先给面试官的短答案

立即停止写入和自动清理任务，隔离误操作账号并保留 binlog、审计日志和现场。根据删除时间点执行备份加 PITR
恢复到隔离实例，校验后再按业务键合并缺失数据，不能直接把整库回滚覆盖事故后的合法写入。

## 核心拆解

- 确认库表、条件、时间窗口、影响行数和后续写入，阻止 binlog 过期及副本继续执行危险操作。
- 在隔离环境恢复最近全量备份并重放 binlog 到删除前，保留恢复清单和校验和。
- 比较当前库与恢复库，只回补误删记录及必要关联，处理主键冲突、状态演进和外部副作用。
- 完成业务对账和审计，实施最小权限、危险 SQL 审批、软删除边界与定期恢复演练。

## 深度完善：生产事故 Runbook

围绕「生产数据库误删数据，如何恢复？」，事故题不要直接猜根因。高分回答要按时间线推进：先止血，再定位，再恢复，
最后补齐长期防线。面试官更看重你是否能控制影响面，而不是一次性猜中答案。

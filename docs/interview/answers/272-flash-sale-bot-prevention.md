# 272 秒杀如何防止黄牛？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

秒杀防黄牛要从账号、设备、行为、频率、资格、风控和履约规则多层治理。
常见手段包括登录态校验、验证码、设备指纹、限购、黑名单、行为风控、令牌签名、接口混淆和异常订单审核。

防黄牛不是靠一个验证码解决，而是风控体系。

## 风控维度

维度包括：

- 用户账号。
- 手机号。
- 设备指纹。
- IP 和代理。
- 收货地址。
- 支付账户。
- 行为轨迹。
- 请求频率。
- 历史风险。

单一维度容易被绕过。

## 技术手段

手段包括：

- 登录和实名认证。
- 动态验证码。
- 活动资格预约。
- 一人一单限购。
- 令牌防伪和过期。
- 请求签名。
- 频率限制。
- 黑灰名单。
- 机器行为识别。

高风险用户可以进入排队或人工审核。

## 业务手段

业务上可以：

- 限制同地址购买数量。
- 限制同支付账户。
- 延迟发货审核。
- 取消异常订单。
- 预约抽签。
- 分批放货。

技术和业务规则要结合。

## 电商系统实践

秒杀请求要校验登录用户、设备、活动资格和令牌签名。

同一用户、设备、地址和支付账户的异常频率要进入风控，命中高风险时拒绝或进入审核。

# 309 按用户分片和按订单分片有什么区别？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

按用户分片适合用户维度查询，例如用户订单列表；按订单分片适合订单号定位和均匀写入。
两者的区别在于核心查询路径、数据分布、热点风险、跨分片查询和二级索引建设不同。

选择哪种方式取决于订单系统最重要的访问模式。

## 按用户分片

优点：

- 用户订单列表单分片查询。
- 用户维度事务更容易聚合。
- 用户数据归属清晰。

缺点：

- 超级用户可能热点。
- 按订单号查询需要知道用户或路由表。
- 商家后台查询可能跨分片。

## 按订单分片

优点：

- 写入分布更均匀。
- 订单详情按订单号定位方便。
- 避免用户热点更容易。

缺点：

- 用户订单列表可能跨分片。
- 需要用户订单读模型或索引表。
- 用户维度聚合更复杂。

## 混合方案

可以：

- 订单主表按订单 ID 分片。
- 用户订单索引表按用户 ID 分片。
- 商家订单读模型按商家 ID 分片。

写模型和读模型可以分开设计。

## 在 eMall 项目中怎么讲？

如果 eMall 用户端订单列表访问极高，可以按用户 ID 分片订单读模型。

订单主写入可以按订单 ID 均匀分片，通过事件同步用户和商家维度读模型。

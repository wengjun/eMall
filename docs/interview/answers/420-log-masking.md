# 420 日志脱敏如何实现？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

日志脱敏要在日志写入前对敏感字段进行识别、掩码、哈希或删除。常见敏感字段包括手机号、身份证、
银行卡、token、secret、地址和支付信息。

脱敏要在统一日志组件、网关、审计和异常处理链路中落地，不能靠开发者手工记忆。

## 脱敏方式

方式：

- 掩码显示。
- 删除字段。
- HMAC hash。
- 分类分级记录。
- 禁止记录原始 body。
- 异常堆栈过滤敏感参数。

不同字段选择不同方式。

## 常见规则

示例：

```text
13812345678 -> 138****5678
idCard -> 110***********1234
Authorization -> [REDACTED]
secret -> [REDACTED]
```

token 和 secret 通常应完全移除。

## 落地点

落地点：

- 统一日志框架。
- Web 过滤器。
- RPC 拦截器。
- 异常处理器。
- 审计日志组件。
- 日志采集管道。

越靠近源头越好。

## 电商系统实践

大型电商系统订单日志可以记录 `orderId`、`userId` 和 trace ID，但不能记录完整手机号、地址、身份证和
支付凭证。

开放平台请求日志要移除 `Authorization`、`secret` 和签名原文，只保留必要摘要用于排查。

# 564 某个新版本发布后错误率上升，如何判断是否回滚？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

先按版本比较错误率、P99 和业务成功率；新版本与异常高度相关且触发门禁时立即暂停放量并回滚。
同时确认数据库或消息契约是否可逆，避免代码回滚后因不兼容数据造成二次事故。

## 核心拆解

- 比较 canary 与 stable 的相同流量切片，排除地域、租户和请求类型偏差。
- 对齐镜像、配置、特性开关、数据库迁移和依赖版本，定位首个异常 Span 和错误码。
- 达到自动回滚阈值就执行预案；若存在不可逆迁移，优先关闭新功能并部署向后兼容修复。
- 回滚后验证流量、积压和数据一致性，记录门禁为何成功或失效并补充测试。

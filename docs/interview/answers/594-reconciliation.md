# 594 你为什么要做对账？

[返回按分类学习面试题](../README.md)

## 核心判断

超时、网络分区、人工操作和第三方最终状态都会造成“本地认为失败、渠道实际成功”等差异。在线事务只能降低差错概率，对账负责独立发现静默错误，是资金和库存闭环的最后防线。

## 取舍依据

- 明确权威来源和比较键，例如支付以渠道账单与本地支付流水按交易号、金额、币种核对。
- 区分单边账、金额不符、状态不符和重复记录，不同差异采用不同修复动作。
- 自动修复必须幂等、有审批阈值和审计记录，高风险差异进入人工队列。
- 记录覆盖率、差异率、修复时长和未决金额，避免任务“运行成功”却漏账。

## 项目证据与边界

eMall 为订单、支付和库存设计独立对账与补偿链路。对账不是日终 SQL 报表，也不能替代在线幂等；它必须可重跑、可分片、可追踪到每一条差异。

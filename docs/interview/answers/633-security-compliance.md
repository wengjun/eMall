# 633 讲一次你处理安全或合规风险的经历。

[返回按分类学习面试题](../README.md)

## 本题考察

要展示风险判断、保密沟通和长期控制。回答时避免披露真实密钥、漏洞细节或客户敏感数据。

## 选材与证据

- 说明资产、攻击路径、影响和严重度，区分已利用事件与潜在风险。
- 先隔离、轮换、撤权或关闭入口，再保存证据并按流程通知安全与法务。
- 用威胁模型找到根因，修复代码、配置、权限和供应链中的系统缺口。
- 通过扫描、审计、演练或复测证明风险关闭，并跟踪残余风险。

## 追问准备

说明如何平衡披露与保密、业务要求继续运行时怎么办，以及为什么原有控制没有发现问题。

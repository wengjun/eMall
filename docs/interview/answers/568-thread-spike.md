# 568 线程数暴涨，如何定位？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

先按线程名和状态统计新增线程，保存多次线程转储，判断是无界创建、阻塞下游、重试风暴还是死锁。
通过限流、熔断问题下游和回滚异常版本止血，不能仅提高操作系统线程上限。

## 核心拆解

- 比较线程总数、创建速率、RUNNABLE/BLOCKED/WAITING 分布和各线程池 active/queue/reject。
- 连续采集线程栈，定位共同调用点、锁、Socket 读取和未指定 Executor 的异步任务。
- 隔离慢下游并限制新请求，关闭重复调度任务；线程泄漏版本应滚动回滚。
- 所有 Executor 改为有界且可观测，设置超时、拒绝策略、生命周期关闭和线程数告警。

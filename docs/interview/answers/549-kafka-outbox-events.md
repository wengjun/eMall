# 549 设计 Kafka Outbox 可靠事件系统。

[返回按分类学习面试题](../README.md)

## 题目

设计 Kafka Outbox 可靠事件系统。

## 先给面试官的短答案

可靠事件系统在同一本地事务内写业务事实和 Outbox，Relay 以可竞争领取的批次投递 Kafka，
消费者按事件 ID 幂等处理。它提供至少一次语义，顺序、重试、死信、重放和积压治理仍需显式设计。

## 核心拆解

- Outbox 保存 eventId、aggregateId、aggregateVersion、type、schemaVersion、payload 和投递状态。
- Relay 使用短事务领取批次，发送成功后条件更新状态；发送成功但更新失败会重复投递，因此消费者必须幂等。
- Kafka 以 aggregateId 作为分区键保证聚合内顺序，消费者拒绝旧版本并隔离无法兼容的事件。
- 监控最老事件年龄、发送失败率、Kafka lag 和 DLQ；重放需要审批、速率限制和完整审计。

# 567 JVM Full GC 频繁，如何处理？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

先确认 Full GC 的触发原因、暂停时间和回收效果。若回收后老年代仍持续增长，应保存 JFR 和堆转储定位泄漏；
若是分配压力、元空间或显式 GC，则按对应证据止血，不能只调大堆。

## 核心拆解

- 查看 GC 日志中的触发原因、堆各区占用、晋升失败、停顿和回收后存活量。
- 结合 JFR、类直方图和 dominator tree 判断缓存无界、队列积压、ClassLoader 泄漏或大对象问题。
- 限流并暂停高分配非核心任务，摘除异常实例；生成证据后再滚动重启，避免全量同时重启。
- 修复对象生命周期或队列边界后做相同流量压测，验证分配率、停顿和内存稳定平台。

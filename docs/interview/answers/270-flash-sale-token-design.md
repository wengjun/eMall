# 270 秒杀令牌如何设计？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

秒杀令牌是进入下单链路的资格凭证，数量通常不超过库存和系统处理能力。
令牌要按活动和 SKU 维度生成，支持限量发放、防伪、防重复使用、过期、绑定用户和核销。

令牌的目标是让后端只处理有机会成功的请求。

## 令牌内容

令牌可包含：

- 活动 ID。
- SKU ID。
- 用户 ID。
- 过期时间。
- 随机数。
- 签名。
- 版本号。

不能使用可预测的简单自增值。

## 发放方式

方式包括：

- 活动开始前预生成。
- 按库存动态发放。
- Redis 原子扣减发放。
- 队列排队后发放。
- 按用户风控分层发放。

发放数量要考虑库存、超卖保护和后端容量。

## 核销要求

核销要保证：

- 一次性使用。
- 和用户绑定。
- 和活动绑定。
- 有过期时间。
- 原子校验和扣减。
- 失败可追踪。

令牌核销失败不能继续下单。

## 电商系统实践

秒杀开始后，网关或秒杀服务先校验用户资格并尝试领取 SKU 令牌。

只有拿到有效令牌的用户才能进入订单创建流程；没有令牌的请求直接返回售罄或排队提示。

# 389 倒排索引是什么？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

倒排索引是从词到文档的映射。普通索引更像从文档找到字段值，倒排索引是把文本分词后，记录每个
词出现在哪些文档中，从而快速根据关键词找到商品。

搜索引擎的全文检索能力主要建立在倒排索引上。

## 简单例子

商品文档：

```text
1: Apple phone case
2: Apple charger
3: Android phone case
```

倒排索引：

```text
apple -> [1, 2]
phone -> [1, 3]
case -> [1, 3]
charger -> [2]
```

搜索 `phone case` 时，可以快速找到同时包含这些词的文档。

## 包含信息

倒排索引通常包含：

- 词项。
- 文档 ID 列表。
- 词频。
- 位置信息。
- 字段信息。
- 权重信息。

这些信息支持相关性打分和短语查询。

## 和数据库索引区别

区别：

- 数据库索引适合精确匹配和范围查询。
- 倒排索引适合文本检索。
- 倒排索引先分词再建立词到文档映射。
- 搜索结果通常需要相关性排序。

二者服务不同查询模型。

## 在 eMall 项目中怎么讲？

eMall 商品标题、品牌、类目、卖点和属性会进入搜索文档。搜索引擎对这些字段分词并建立倒排索引。

用户搜索“手机壳”时，系统通过倒排索引召回相关商品，再结合销量、价格、评分和广告做排序。

# 610 你如何证明这个系统不是玩具项目？

[返回按分类学习面试题](../README.md)

## 核心判断

不能靠模块数量、技术名词或 README 中的目标证明。生产级程度必须由可执行证据说明：业务不变量被测试，故障可以控制和恢复，发布可以回滚，数据可以对账，容量结论可以复现。

## 证据清单

- 交易链路有状态机、唯一约束、幂等、Outbox、补偿和对账，并覆盖重复、乱序、超时与并发测试。
- 依赖有超时预算、限流、隔离、熔断和恢复斜坡，且通过故障注入验证。
- 部署有探针、灰度门禁、兼容迁移、监控告警、Runbook、备份恢复与安全基线。
- 构建、单元测试、容器集成测试和文档链接能够自动校验，结果可复现。

## 必须诚实说明的边界

一个电商工程可以展示生产工程方法，但代码仓库本身不能证明已经承载十亿用户或百万并发。
只有目标环境中的容量报告、长期 SLO、事故数据和灾备演练结果才能完成这一证明；面试时应明确区分设计能力与运行事实。

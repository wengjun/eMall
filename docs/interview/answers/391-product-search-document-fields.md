# 391 商品搜索文档应该包含哪些字段？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

商品搜索文档应围绕召回、过滤、排序、展示和权限控制设计。常见字段包括商品 ID、SKU ID、标题、
品牌、类目、属性、价格、库存状态、上下架状态、销量、评分、商家、地区、标签和更新时间。

搜索文档是读模型，不一定等于商品表结构。

## 召回字段

召回字段包括：

- 标题。
- 副标题。
- 品牌。
- 类目。
- 卖点。
- 属性词。
- 同义词扩展字段。

这些字段会参与分词和倒排索引。

## 过滤字段

过滤字段包括：

- 类目 ID。
- 品牌 ID。
- 价格区间。
- 商家 ID。
- 上下架状态。
- 库存状态。
- 地区。
- 是否自营。

过滤字段通常需要结构化索引。

## 排序和展示字段

排序字段包括：

- 销量。
- 评分。
- 价格。
- 新品分。
- 转化率。
- 广告分。
- 运营权重。

展示字段包括主图、标题、价格摘要和促销标签，但大字段不要放太多。

## 电商系统实践

大型电商系统的搜索文档可以由 `product`、`pricing`、`inventory`、`review` 和 `merchant` 多个服务数据
聚合生成。

商品库是事实来源，搜索文档是面向查询优化的读模型。下单时仍要回到价格和库存服务做最终校验。

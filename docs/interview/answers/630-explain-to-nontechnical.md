# 630 讲一次你把复杂问题讲清楚给非技术人员的经历。

[返回按分类学习面试题](../README.md)

## 本题考察

沟通成功的标准是对方能够做出正确决策，而不是听懂全部技术术语。选择涉及风险、成本或交付取舍的真实场景。

## 选材与证据

- 先判断受众需要决定什么、已知什么和最关心什么。
- 用业务影响、概率、时间和选项组织内容，技术机制只解释到支撑决策的深度。
- 使用简单图示或类比，但明确类比失效的边界。
- 通过复述、问题和书面结论确认理解，并记录 owner 与下一步。

## 追问准备

说明最初哪种说法没有奏效、如何处理坏消息，以及沟通后对方具体改变了什么决策或行为。

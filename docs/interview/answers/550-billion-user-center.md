# 550 设计面向 10 亿用户的用户中心。

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

十亿用户中心应分离身份账户、登录凭证和用户档案，按 userId 及 home region 分片。登录和身份变更走强保护链路，
档案读取使用缓存和区域读副本，同时满足唯一性、隐私、审计和账号生命周期要求。

## 核心拆解

- 全局 ID 与登录标识分离，手机号或邮箱通过受控索引定位 userId，敏感字段加密且日志只保留脱敏值。
- 用户档案按稳定路由分片，路由目录可持久化、可迁移并带版本，避免固定取模阻塞扩容。
- 登录链路实施密码哈希、MFA、设备风控、限速和令牌撤销，安全事件进入不可篡改审计。
- 缓存热点档案但不缓存永久唯一事实；设计注销、冻结、合并、密钥轮换和隐私删除工作流。

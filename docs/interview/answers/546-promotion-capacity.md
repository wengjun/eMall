# 546 设计大促容量保障方案。

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

大促容量保障从业务峰值模型开始，把目标流量折算到网关、订单、库存、支付、数据库和 Kafka，
通过分布式压测验证单 Cell 容量，再配置准入、预热、降级、扩容和回滚门禁。

## 核心拆解

- 使用历史峰值、活动机制和转化率计算读写 QPS、并发、连接数、消息速率及存储增量，并保留安全余量。
- 在隔离环境和影子流量中验证 P99、错误率、库存正确性、MQ lag 与数据库余量，禁止只看平均吞吐。
- 提前扩容、预热缓存和连接池，热点 SKU 独立保护，非核心推荐、评价和报表按优先级降级。
- 活动期间以业务成功率为主指标，设置自动暂停放量和回滚条件，结束后完成对账及容量复盘。

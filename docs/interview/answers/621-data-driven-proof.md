# 621 讲一次你用数据证明方案有效的经历。

[返回按分类学习面试题](../README.md)

## 本题考察

数据不是在结论后补一张图。应展示你如何预先定义成功标准、控制混杂因素，并允许数据否定原方案。

## 选材与证据

- 给出基线、样本范围、指标定义和观测窗口，区分业务指标与系统指标。
- 通过灰度、A/B、对照压测或时间序列比较减少流量季节性和版本差异。
- 同时观察护栏指标，避免 P99 降低却造成错误率或成本上升。
- 说明统计结果如何改变放量、回滚或后续优化决策。

## 追问准备

准备解释数据质量、异常值、因果与相关的区别，以及指标没有改善时你是否终止过自己的方案。

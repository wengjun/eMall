# 614 讲一次你推动团队采用更好工程实践的经历。

[返回按分类学习面试题](../README.md)

## 本题考察

面试官关心你能否改变团队默认行为，而不只是写一份规范。选择代码评审、测试、发布、可观测或安全治理中有真实采用阻力的案例。

## 选材与证据

- 用缺陷、返工、事故或交付时长说明旧做法的成本。
- 先在小范围试点，收集收益和额外成本，再调整规则。
- 把实践做进脚手架、CI 门禁或默认配置，降低遵守成本。
- 用采用率、逃逸缺陷、回滚率或评审周期证明长期效果。

## 追问准备

说明谁反对、反对理由是否合理、你删掉过哪些过重规则，以及离开后该实践为何仍能持续。

# 576 配置中心推错配置，如何回滚？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

立即冻结配置发布并回滚到已验证版本，关键配置使用服务端版本和签名，客户端必须保留 last-known-good。
回滚后核对各实例实际生效版本，避免只看配置中心显示成功。

## 核心拆解

- 确认变更项、发布人、目标范围、生效时间和受影响实例，对齐错误率与配置版本。
- 使用不可变历史版本回滚，禁止手工重新输入旧值；高风险配置需双人审批和灰度。
- 客户端校验 schema、范围和安全边界，不合法配置拒绝生效并继续使用上一个安全版本。
- 通过实例指标确认收敛，处理离线实例和缓存配置，补预发布验证与自动回滚门禁。

# 578 日志系统故障是否会影响交易链路？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

日志系统故障不应阻塞交易链路。应用应使用有界异步缓冲并在写满时丢弃低优先级日志，同时保留关键审计的可靠通道；
若同步日志或磁盘写满影响请求，应立即降级日志并保护本地磁盘。

## 核心拆解

- 比较请求 P99、日志队列、Appender 阻塞、磁盘占用和采集 Agent 状态，确认是否发生反压。
- 将调试和采样日志降级，限制堆栈洪峰；关键资金审计进入独立、持久且受监控的通道。
- 日志平台恢复后限速补传，避免 Agent 和网络恢复流量再次冲击应用。
- 补日志队列满、磁盘满和采集端不可用的故障测试，指标与 Trace 不能依赖同一失败通道。

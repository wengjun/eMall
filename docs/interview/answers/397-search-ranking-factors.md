# 397 搜索结果排序考虑哪些因素？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

搜索排序通常综合相关性、销量、价格、库存、评分、点击率、转化率、商家质量、履约能力、个性化、
广告和运营规则。排序目标不是单纯文本匹配，而是让用户更快找到合适商品并提升交易效率。

排序要兼顾用户体验、商业目标和合规边界。

## 基础相关性

相关性因素：

- 标题匹配。
- 品牌匹配。
- 类目匹配。
- 属性匹配。
- 短语匹配。
- 关键词权重。

相关性是排序的底座。

## 业务因素

业务因素：

- 销量。
- 评分。
- 价格竞争力。
- 库存状态。
- 配送时效。
- 退货率。
- 商家服务质量。

这些影响用户决策和履约体验。

## 个性化和商业化

还可能包括：

- 用户偏好。
- 地区。
- 历史点击。
- 优惠活动。
- 广告出价。
- 运营置顶。

广告和运营干预要有标识和规则边界。

## 电商系统实践

大型电商系统搜索排序可以先用相关性召回，再叠加销量、评分、价格、库存和商家服务分。

如果商品无货或履约能力差，即使文本相关性高，也应降低排序。广告商品可以参与混排，但不能破坏
基础相关性和用户体验。

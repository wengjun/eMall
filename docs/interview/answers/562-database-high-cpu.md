# 562 数据库 CPU 100%，你先看什么？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

先确认是否影响核心写入并限制非核心查询，然后从正在执行 SQL、慢 SQL、调用量、执行计划和锁等待建立证据。
不能仅凭 CPU 高就重启数据库；应先停止异常流量或回滚变更，再修正索引与查询模式。

## 核心拆解

- 查看 Top SQL 的总 CPU、调用次数和单次耗时，区分单条坏 SQL 与流量放大。
- 对齐发布、报表任务、索引变更、统计信息和数据倾斜，使用执行计划确认扫描行数及临时排序。
- 取消或限速非核心大查询，回滚问题版本并保护连接池；保留现场后再考虑故障切换。
- 修复后用生产规模数据验证计划稳定性，补慢 SQL 门禁、分页上限和容量告警。

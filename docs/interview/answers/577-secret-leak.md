# 577 Secret 泄露后如何应急？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

把泄露视为已被利用：立即吊销或轮换密钥，限制对应主体权限并保存审计证据；随后搜索访问记录和异常行为，
评估数据影响并按合规要求通知。只删除 Git 历史或日志不能使旧密钥失效。

## 核心拆解

- 确认密钥类型、权限、暴露位置、时间窗口和可访问系统，先禁用高风险凭据。
- 生成新版本并分阶段切换调用方，验证后吊销旧版本；数据库凭据同时终止旧会话。
- 查询网关、云审计、数据库和密钥服务日志，识别异常 IP、操作和数据导出。
- 清理代码、镜像、日志与制品中的秘密，启用 secret scanning、最小权限、短期凭据和自动轮换。

# 583 大促前你会做哪些检查？

[返回按分类学习面试题](../README.md)

## 先给面试官的短答案

大促前检查必须以可验证证据为准：冻结目标与流量模型，完成容量压测、故障演练、数据校验、发布回滚和人员值守，
并设置明确的 Go/No-Go 门槛。缺少核心链路容量或恢复证据时应降低活动规模。

## 核心拆解

- 核对活动规则、SKU、价格、库存、优惠预算和预热数据，演练重复请求、售罄及支付超时。
- 用目标混合流量验证网关、订单、库存、支付、数据库、Redis 和 Kafka 的 P99 与安全余量。
- 确认扩容、限流、降级、熔断半开、灰度、回滚、备份恢复和对账补偿均可执行。
- 建立指挥体系、变更冻结、仪表盘和停止条件，活动后安排积压追赶及业务对账。

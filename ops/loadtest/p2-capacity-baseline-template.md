# 容量基线人工复核模板

Java coordinator 会生成 JSON 和 Markdown 报告。本模板用于评审会上补充自动报告之外的运行背景、变更决策和签字，
不能替代 `capacity-evidence.json`。

## 证据身份

- 日期与时区：
- Git commit（40 位）：
- 镜像 digest：
- 预生产环境与 Cell：
- 发布/配置版本：
- 执行人和复核人：
- 自动报告路径：

## 资源和数据

- 网关、应用服务实例与每实例规格：
- MySQL 分片数、实例规格、连接预算与副本拓扑：
- Redis 分片/副本、内存和网络规格：
- Kafka broker、分区、副本和磁盘规格：
- Elasticsearch 节点、分片和副本：
- 压测 worker 数、单 worker CPU/内存/网络：
- 注册用户、活动用户、订单、SKU、库存和索引文档规模：
- 热点 SKU 比例、热用户比例和流量混合：
